## Extracted behavior

- Public navigation is spacious and focused on project discovery, services,
  about, and contact.
- The UI layer supports desktop navigation, grouped menus, sidebar layouts, and
  mobile sheet behavior.
- Active and hover states are visible without overwhelming the content.

## BeeZ treatment

- Keep navigation labels concise.
- Use the lime role for active/selected state and primary contact action.
- Preserve a strong relationship between navigation, project imagery, and the
  page's editorial heading.
- Mobile navigation should be a bounded drawer or sheet, not a separate visual
  language.
